# מערכת TRACE — סטודיו סקיצה תעשייתית

כלי אינטראקטיבי (עמוד HTML יחיד, ללא תלויות) שמייצר גיליונות קווים לתרגול *trace* ב‑Procreate.
המטרה: לבנות זיכרון‑שרירי לצורות בפרספקטיבה — הבסיס של כל סקיצת מוצר תעשייתי.

## שני מצבים

**1. יסודות — קווים ל‑trace**
הכלי מצייר בעצמו קווים נקיים בפרספקטיבה אמיתית (נקודות מגוז אמיתיות על קו האופק, לא זיוף):
- חבורת פרימיטיבים / קופסה / גליל / חרוט / כדור / מטח אליפסות
- פרספקטיבה של נקודה אחת, שתיים או שלוש
- שליטה בכמות הצורות, משקל הקו, קווי בנייה כחולים (לא‑מצלם), קווים נסתרים ורשת רקע
- ייצוא **PNG** ברזולוציה גבוהה (2400×1800) לייבוא ישיר, או **SVG**
- כל גיליון כולל *title block* עם סוג התרגיל, הפרספקטיבה, מספר הגיליון והתאריך

**2. מוצר אמיתי — פרומפט לרפרנס**
שאלון קצר שמוציא פרומפט מוכן להדבקה במחולל תמונות (Midjourney / DALL·E וכו') כדי לקבל
רפרנס של מוצר אמיתי לתרגול. מפיק שתי גרסאות — צילום/ציור מפורט, וגרסת ציור‑קו נקייה שהכי מתאימה ל‑trace.

## זרימת עבודה ל‑Procreate
1. ייצא PNG (או השתמש בפרומפט לרפרנס) ושמור לתמונות ב‑iPad
2. Procreate → פעולות → הוסף → הכנס תמונה
3. פתח שכבה חדשה מעל הרפרנס (אפשר להוריד את שקיפות שכבת הרפרנס)
4. עבור על הקווים לאט. אחר‑כך כבה את הרפרנס ונסה לשחזר מהזיכרון

## הפעלה
פותחים את `index.html` בכל דפדפן — כולל Safari ב‑iPad. אין צורך בשרת או בהתקנה.
העמוד עצמאי לחלוטין (הקווים נוצרים ב‑JavaScript, הגיליון תמיד על רקע לבן להדפסה/trace נוחים).

## מבנה
- `index.html` — הכלי כולו (עיצוב, מנוע הפרספקטיבה, וייצוא), קובץ עצמאי אחד.

הבנייה: מנוע גאומטרי מחשב חיתוכי קווים אל נקודות המגוז, ודרגת פתיחת האליפסות גדלה עם המרחק מקו האופק — בדיוק כמו בבנייה ידנית.
